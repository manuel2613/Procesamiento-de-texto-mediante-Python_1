El script original fue diseñado para automatizar la extracción, limpieza, conteo y construcción de redes de literatura científica. Es posible adaptar la ruta de entrada de un corpus literario acorde a las necesidades del proyecto a desarrollar. 
Aclaración importante: la versión localizada de r1.py contenía rutas hacia otro proyecto documental; por ello, para el proyecto que se desarrolló, los resultados no se asumieron de manera automática, sino que se contrastaron con la base bibliográfica, los documentos de resultados y los archivos generados para el estudio realizado en el ámbito forestal.
